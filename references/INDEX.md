# workerstack packages

Every published `@workerstack/*` package, one line each: its npm page and what it does. `repo sync` lists the ones a repo does not install under `repo:available` in that repo's `references/INDEX.md`; the installed ones are under `repo:stack`, linked to their own `references/INDEX.md`.

- [@workerstack/repo](https://www.npmjs.com/package/@workerstack/repo): Agent workflows, code standards, quality gates, CI and repo management
- [@workerstack/system](https://www.npmjs.com/package/@workerstack/system): Manage every OS dependency, built-in or custom, from one config
- [@workerstack/database](https://www.npmjs.com/package/@workerstack/database): Schema, queries and migrations for SQLite, D1 and Postgres
- [@workerstack/testing](https://www.npmjs.com/package/@workerstack/testing): End-to-end matrix testing for APIs, web apps and Workers
