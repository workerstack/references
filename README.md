# workerstack references

workerstack is an opinionated stack for building full-stack platforms end to end, Cloudflare first, shipped as standalone `@workerstack/*` npm packages that each work on their own and work better together.

This repo is an index for agents. Start from a package's `docs/INDEX.md`.
